如何让测试者手机正常扫码接入？

解决“网络出错，无法显示该页面”及手机传感器 HTTPS 权限要求

为什么之前扫码会提示“网络出错”？

当前页面运行在受限的沙盒预览窗口中，没有公网域名。手机扫码需要访问一个真实可达的 HTTPS 公网网址（iOS 和主流安卓浏览器也要求 HTTPS 才能读取陀螺仪与加速度计）。

最快 2 步上线方案（约 30 秒，免费无需后端）：
  1. 点击面板中的 “⬇ 下载单文件 HTML” 保存 har_knn_monitor.html（或改名为 index.html 放入一个空文件夹）。
  2. 将该文件部署到任意免费静态托管服务：
    • Netlify Drop：打开 app.netlify.com/drop，把文件夹拖进去立即获得 https://xxx.netlify.app。
    • GitHub Pages / Vercel / Cloudflare Pages：上传后即可获得永久 HTTPS 链接。
  3. 直接用电脑打开那个 HTTPS 网址作为大屏（二维码会自动指向该网址），测试者手机扫码即可立即接入并实时同步数据！
